# 本地文件夹实施任务

1. 按贡献指南确认 [需求](spec.md)和[方案](plan.md)，在 [工单 #3](https://github.com/yiyualt/dsh-code-wiki/issues/3) 记录受理和认领。
2. 接入文件系统读取。用普通目录和 Git 仓库的子目录验证读取范围、未提交内容、文件过滤和空目录反馈。
3. 在总览、章节和存储中支持以 `commit: null` 保存和打开新建的本地 Wiki。验证重新打开、从当前文件生成章节、已有本地 Git 与 GitHub 文档的兼容性。
4. 调整前端对新旧文档的校验，更新现有入口的提示和 README。通过文件夹选择器验证从生成总览到生成章节的流程。
5. 运行 `npm run check` 并核对工单验收条件。提交并推送工作分支，向 `main` 提交 PR，在 PR 中链接工单和规格，记录实际验证结果。
