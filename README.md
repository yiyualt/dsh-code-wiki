# DSH 代码百科

DeepSeek Harness Web 插件。在侧栏打开「代码百科」，选择公开 GitHub 仓库或本地 Git 仓库，生成带分层架构图和源码引用的 Wiki。
DSH 代理通过只读的目录、代码读取和符号搜索工具探索固定提交。仓库说明可用于定位文件，架构要点、图节点和连线的引用来自代理实际读到的源码或构建配置。模型调用失败或有效证据不足时，生成任务会显示错误。

## 打包和安装

```sh
npm pack
dsh plugin --profile web add ./dsh-code-wiki-0.7.3.tgz
```

也可以在 DSH 的「插件 → 添加插件」输入安装包的绝对路径，安装后启用。若 DSH 提示需要重启，请按原命令重启 Web 服务。

## 试用

1. 确认 DSH 的默认模型或插件单独配置的模型可用。
2. 阅读时可点击「新建 Wiki」打开生成表单。选择「GitHub 地址」并输入公开仓库地址，或在「本地仓库」中点击「选择文件夹」，选中已克隆的仓库。
3. 在左侧目录选择章节，在右侧阅读正文。点击图中节点、连线或正文引用可打开该提交对应的文件和行号。点击左上角「返回文档列表」可切回已保存文档。

本地模式读取当前 `HEAD` 中已提交的文件。它会把选取的文件片段发给所选模型，本地引用由当前 DSH 实例显示。
生成时会显示当前阶段和已耗时。切换面板、刷新或关闭浏览器页面后，任务继续在运行中的 DSH 服务上执行。重新打开「代码百科」可以查看进行中的任务。单次生成上限为 15 分钟。

每次生成完成后，文档会保存到当前 DSH profile 的 `dsh-code-wiki/documents/` 目录。本地仓库的引用片段随文档保存。重新打开代码百科后，可从「已保存文档」按仓库查看此前保存的版本。

## 选择本地模型配置

插件默认使用 DSH 当前的默认模型。可在 Web profile 的 `cordis.patch.yml` 中为「代码百科」单独配置一个本地文件。

```yaml
- id: dsh-code-wiki
  config:
    modelConfigFile: /path/to/config.local.json
```

插件从该文件的 `judge` 项读取 Chat Completions 端点、模型和凭据。端点需支持函数工具调用。
