# DSH 代码百科

在 DeepSeek Harness Web 侧栏打开「代码百科」，选择公开 GitHub 仓库或本地 Git 仓库。点击「生成文档」后，`repo-design-wiki` Skill 使用 DSH 当前模型，根据仓库已提交的源码生成整仓总览、逻辑架构图、模块交接图和 RQ 目录。打开新 Wiki 默认显示总览。逻辑架构图用横向层级、能力组和简短组件标签展示系统结构。多个层共同使用的能力可放在侧边竖列，并标明服务的层。具体职责在正文里说明。模块交接图展示实际的调用或数据交接。每章开头标明对应模块和交接，可跳到总览里的模块图。点击「生成本章」后按需生成正文、源码引用和需要的图。章节使用拟定目录时的 Git 提交。

## 本地安装

使用 Node.js 22 或更高版本，在仓库目录运行下面的命令。安装包需保留在指定路径，供 DSH profile 加载。

```sh
npm ci
npm run check
npm pack --pack-destination ~/.dsh/plugin-packages
dsh plugin --profile web add ~/.dsh/plugin-packages/dsh-code-wiki-0.34.1.tgz
```

所选仓库的源码片段会交给当前模型用于生成总览、目录和章节正文。Skill 根据本章内容选图，并把图形数据绘成附源码引用的 SVG。插件负责在阅读页显示。Skill 的组织原则见 `skills/repo-design-wiki/SKILL.md`。

图按阅读区宽度等比例显示。点击「查看大图」可放大、缩小或恢复适合宽度。每章按文件编号，点击正文里的引用编号可跳到下方的源码位置。GitHub 文件路径打开生成时对应提交里的文件。

章节用具体输入和关键源码片段解释结果如何产生。正文直接呈现表格，图生成后放在首次说明它的段落下方。已保存章节会恢复图的位置。

总览正文、两张图和 RQ 目录分别通过工具校验后一起保存。章节正文和每张图通过校验后会依次显示。正文和已完成的图会保留，页面显示尚未交付的内容遇到的问题。DSH 服务日志中的 `[dsh-code-wiki]` 记录请求编号、生成类型、阶段和校验结果，便于定位失败。

文档库保存在当前 DSH profile 的 `dsh-code-wiki/documents/`。总览和目录完成时创建文档。各 RQ 的正文和图通过核对后逐步保存。刷新页面或重启 DSH 后，可以从文档库继续阅读已有结果，并生成未完成的章节。旧版归档在同一目录下可供阅读。

文档库可以归档整份 Wiki，在「已归档」中阅读或恢复。删除会永久移除选中的 Wiki 及其章节，确认弹窗支持按回车删除、按 Esc 取消。
