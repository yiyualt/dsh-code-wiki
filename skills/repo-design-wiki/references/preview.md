## 项目概览

这个示例项目是一个命令行任务工具。它从 JSON 文件读取任务，逐项执行，最后输出每项任务的结果。

## 快速开始

准备一份任务清单 `tasks.json`，再从命令行启动工具。

```sh
task-runner run ./tasks.json
```

执行结束后，终端会显示成功与失败的任务数量。

## 系统架构

命令行入口接收文件路径，任务读取器负责解析和校验，执行器处理每项任务，报告模块汇总结果。

## 核心模块

- **任务读取器**检查任务标识和类型。
- **执行器**按任务类型选择处理函数。
- **报告模块**把每项任务的状态和错误写入结果。

## 关键流程

1. 读取并校验任务清单。
2. 依次执行任务，记录每项结果。
3. 汇总成功与失败，并返回本次运行的退出状态。

## 扩展指南

新增一种任务时，先声明输入字段，再注册对应的处理函数。用包含有效输入和缺失字段的两份清单核对执行结果。
